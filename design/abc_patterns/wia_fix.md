# WiAnote 追加基礎問題の手直し指示

作業フォルダ: ws_WiAnote（out/<lesson>.json を直接編集する）。仕様は wia_SPEC.md、根拠は op_manual.txt（<<<PAGE N>>>）を grep して確認。パケットは wia_pk/<lesson>.md。

## A. 作り直し（同じ id のまま、論点ごと差し替える）
- b-ov4-11 … 確認問題 q-C04-009（起動オプション -r）と同じ。さらに l-ov4 の基礎は起動オプションだらけなので、**起動オプション以外**の l-ov4 本文の論点で作る。
- b-ft1-13 … 確認問題 q-C02-019（イベントモードで記録できるアプリ）と同じ。l-ft1 本文の別の論点で作る。
- b-ft2-15 … l-ov3 の b-ov3-12（分岐ノード）と同じ論点。**分岐以外**の l-ft2 本文の論点で作る。
差し替える問題は、パケット（wia_pk/<lesson>.md）の既存問題と、同じ out ファイル内の他の問題とも重ならないこと。

## B. 正解だけ目立って短い選択肢を直す（意味・正誤は変えない）
次の問題は正解が一番短く、見た目で当たりが付く。**正解を自然に少し具体的にする**か、**誤答を少し短くする**かで、4つの長さをそろえる（正解が一番長くもならないように。中間くらいが理想）。事実を足すときは op_manual.txt で確認。解説・誤答解説の文言も選択肢に合わせて直す。
b-ft5-14, b-sc4-14, b-ov4-12, b-ft2-13, b-ft4-13, b-sc3-13, b-sc1-11, b-sc3-11, b-ft3-12, b-ov4-14, b-ft4-15, b-ft5-13

## 守ること
- 正解位置（correctAnswers）は変えない。選択肢の並び順も変えない。
- 1問直すごとにファイルを保存。他の問題・他のファイルには触れない。
- 最後に、直した問題ごとに「選択肢の字数（前→後）」と、Aで作った問題の論点を短く報告。
