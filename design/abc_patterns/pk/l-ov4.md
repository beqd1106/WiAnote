## レッスン本文
起動と終了の手順、起動オプション、起動パスワード、シナリオファイルの扱いを押さえます。
### 起動と終了
WinActorを起動すると「ようこそ画面」が表示され、新規作成をクリックするとフローチャート画面が開きます。終了はファイルメニューの終了、画面右上の×、タスクトレイアイコンの終了メニューのいずれかで行います。保存されていないシナリオやデータ一覧がある場合は確認画面が表示されます。WinActorは2重起動できないため、起動アイコンを押しても表示されないときは、すでに起動していてタスクトレイに入っていないかを確認します。
### 起動オプション
WinActorはコマンドラインから起動でき、起動ショートカット作成機能でショートカットにオプションを設定できます。代表的なものは、-f（開くシナリオファイルの指定）、-r（起動後にシナリオ実行）、-d（データ一覧ファイルの指定）、-w（指定ミリ秒待機）、-x（実行後にデータ一覧を保存）、-e（実行完了後に終了）、-ec（終了ステータス0／1を返して終了）、-t（タスクトレイに収容して起動）、-p（起動パスワードの指定）、-sl（起動時・実行時のダイアログを非表示）、-sa（指定名で保存して終了）です。これらとWindowsのタスクスケジューラを組み合わせると、定期的な無人実行ができます。
### 起動パスワードとシナリオファイル
起動パスワードはWinActorの起動時に入力を求めるもので、フル機能版でのみ設定・変更・解除ができます。シナリオファイルの拡張子はums7で、フローチャートのほか変数・監視ルール・ウィンドウ識別ルール・イメージ画像などの情報が保存されます。シナリオごとの編集・閲覧・実行を制限したい場合は、起動パスワードではなくシナリオパスワードを使います。

- [付録(画面要素と呼び名について)] WinActorの画面要素における「コンボボックス」の機能説明として正しいものはどれですか。 → テキストフィールドとドロップダウンリストの機能を併せ持ち、文字入力または選択で入力できる画面要素。
- [付録(正規表現の入力例)] WinActorの正規表現の入力例における「^[A-Za-z]+$」の意味として正しいものはどれですか。 → 半角英字のみの文字列かどうかを判別する
- [付録(ログ出力例)] 制御ノード「分岐」の評価時のログ出力例に含まれる情報として、マニュアルに記載されているものはどれですか。 → 「ノード名」の条件式評価：論理式の真偽値、およびノードIDが記載される。
- [付録(パスワードで使用できる文字)] WinActorのパスワードで使用できる英文字について、マニュアルに記載されている注意点はどれですか。 → 大文字、小文字は区別される
- [付録(動画ログについて)] 動画ログを出力する設定について、マニュアルの説明として正しいものはどれですか。 → オプション画面のログタブで「動画ログを出力する」をONにすると、実行中の画面キャプチャをGIF形式で出力する
- [起動オプション] 起動オプション「-ec」でシナリオ実行完了後に返却される終了ステータスの説明として正しいものはどれですか。 → エラー発生時は「1」、正常終了時は「0」が返却される
- [制限事項(ファイル保存場所)] Windows OSの仕様上、ファイル保存の際に管理者権限が必要となるフォルダの例として、マニュアルに挙げられているものはどれですか。 → c:\Program Files
- [制限事項(AcrobatReader)] Acrobat Readerで保護モードが有効な場合に発生しうる事象として、マニュアルに記載されているものはどれですか。 → Acrobat Readerの保護モードが有効な場合、値の取得・設定（表も含む）が記録できない
- [制限事項(EdgeのIEモード)] EdgeのIEモードで保護モード・拡張保護モードが有効な場合に発生しうる事象として、マニュアルに記載されているものはどれですか。 → エミュレーションが記録できない
- [制限事項(Edge IEモード)] EdgeのIEモードで「拡大レベル」が100%以外に設定されている場合に起こる事象として、マニュアルに記載されているものはどれですか。 → WinActor実行時に、ターゲット枠の描画位置がズレてしまう
